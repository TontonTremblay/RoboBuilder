# RoboBuilder project website

**RoboBuilder: A Precision Assembly Benchmark for Robot Foundation Models**

Website: https://vineet2104.github.io/RoboBuilder/

This repository contains only the static project website and demonstration
assets. GitHub Pages serves the root of the `gh-pages` branch; `.nojekyll`
disables Jekyll processing. No build step is needed.

The paper, research code and citation are coming soon. This website repository
does not contain the research codebase or its history.
